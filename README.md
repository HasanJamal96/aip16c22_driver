# aip16c22_driver
 
# Description

An Arduino library for driving the AiP16C22 LCD controller via I2C. Designed for multi-segment LCD panels with support for numerical displays, icons, and custom symbols. Perfect for weather stations, IoT devices, or industrial dashboards.

## Features
- 📟 **7-Segment Display Control**: Show temperature, humidity, and battery levels
- 🔵 **Icon Management**: Bluetooth, Wi-Fi, Frost, Fire, Humidity, Sun, and more
- 🌡️ **Temperature Unit Support**: Auto-switch between °C/°F with indicators
- 🔋 **Battery Visualization**: 5-bar indicator (20% increments)
- 🧹 **Screen Management**: Full clear function and partial updates
